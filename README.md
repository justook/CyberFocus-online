# CyberFocus

一个把「今天做什么、专注了多久、钱花到哪、外面有什么事」收进同一页的个人中控台。
它占的位置是浏览器新标签页——每天打开几十次的那个空白页，换成一屏能用的信息。

**在线使用**：<https://cyberfocus.justoky.xyz>（邀请制，见[如何开始](#开始使用)）
**浏览器插件**：[下载最新版](https://github.com/justook/CyberFocus-online/releases/latest)

---

## 这是什么

要管的东西其实只有几类：今天该做什么、时间花在哪、钱去哪了、外面有什么新动静。它们平时散在四五个应用里，每切一次都要重新找回状态，最后往往是谁叫得响就做谁。

CyberFocus 把它们放在一个网页里，按信息的使用频率排布：抬眼看到的是时间和天气，视线中央是今天的任务，往下是账本，右边是热榜和收藏。打开浏览器第一眼看到的就是这些，不用再"专门打开一个效率应用"。

三个设计上的取舍，决定了它长现在这样：

**一屏优先，不做多级导航。** 没有侧边栏菜单、没有嵌套页面。所有功能都在同一个页面里，靠滚动和页签切换，最多两层。

**手动记录，不接自动采集。** 记账靠一句话输入，任务靠自己勾。不读银行流水、不抓其他应用的数据——省掉了授权、对账和隐私解释，代价是每次记录都要花两秒。

**数据在服务端，客户端只是缓存。** 换设备登录同一个账号就能接上，断网时照常记录、联网后自动同步。目前只有官方实例，不提供自部署。

### 它适合谁

适合：想要一个页面管住日常琐事的人；愿意手动记一笔账的人；不喜欢被通知和红点追着走的人；用电脑为主、手机偶尔看一眼的人。

不太适合：需要多人协作或共享清单的团队；需要手机原生 App 的人（网页在手机上能用，但没有 App）；需要自动导入银行/支付宝流水的人；要长期归档大量资料的人（它不是笔记库）。

## 一天是怎么用的

> **08:40**　打开浏览器，新标签页就是今天的计划。昨天没做完的事带着角标顺延过来，不会消失。
>
> **09:10**　在任务卡上点「开始」，番茄钟跟着走。25 分钟后回来勾掉，专注时长自动计入这个任务。
>
> **12:05**　输一句「午饭 25 微信」，金额、分类、账户、收支方向自己识别，回车记完。
>
> **15:20**　看到一篇要留着的文章，点插件图标 →「添加到导航页」，选个分组就存好了。
>
> **18:30**　「打工人时钟」显示离下班还有多久，这周加了几天班、有没有调休也一起算着。
>
> **周末**　翻一下月报：这个月花在哪、比上月多了还是少了、攒钱计划完成到百分之几。

## 能做什么

### 安排一天

- 待办 / 今日计划 / 本周目标三个页签，做完自动归档，想重做随时退回
- 目标可以拆成子任务，进度按子任务贡献累加，权重手动指定或自动均分
- 每天首次打开自动重置每日任务；前一天没做完的顺延到今天并带角标
- 截止时间分紧急 / 警告 / 正常三档，双击任务直接改内容和时间

### 专注

- 番茄钟带真实进度圆环，可暂停、可改专注时长
- 与任务双向绑定：任务卡上开始计时会自动启动专注，反过来专注结束也能落到任务上
- 专注时长与任务时长分开计账，今日 / 本月 / 今年统计
- 一个番茄结束会提示休息，并显示这台设备累计的专注数据

### 记账攒钱

- 一句话记账：「午饭 25 微信」自动识别金额、分类、账户和收支方向
- 常买的东西存成模板，下次只填金额；也支持手动选择分类、账户、日期
- 两层预算：本月总预算加分类预算
- 「今日建议可花」先预留还没存完的储蓄，再按剩余天数均摊——不是简单地把余额除以天数
- 攒钱计划写明目标与截止日，存钱自动推进进度，并算出每周该存多少
- 周报、月报汇总支出、收入、结余、分类分布和近一年趋势

### 一屏看完

- 大字号时钟，公历农历切换
- 天气：当前温度、未来几天和出行建议，城市可搜索切换
- 热榜：B站、抖音、微博、知乎、豆瓣、贴吧、快手等数十个榜单集中在一处，显示哪些由你决定
- 多源搜索，回车即搜
- 便签：随时记一笔，页签可双击改名

### 收藏与快捷入口

- 分组管理常用网址，拖拽换组、排序、重命名
- 新增链接自动抓网站图标；内网地址和 IP 不会发往外网
- 顶部一排快捷入口，常用站点一步可达
- 配合浏览器插件，任意网页一键收藏

### 用着顺手

- 「🙈 隐私开关」：一键把金额类数字模糊掉，公共场合不用手挡屏幕
- 背景支持动态渐变、自定义图片或每日壁纸
- 桌面三列布局，窄屏自动收敛，手机上可用

## 开始使用

### 1. 拿到邀请码

在线服务是邀请制的，注册时需要一次性邀请码。到 [Issues](https://github.com/justook/CyberFocus-online/issues) 提一条申请，或通过 GitHub 主页上的联系方式找维护者。

之所以不开放注册：实例跑在一台小服务器上，容量有限，先来先得比事后限流体面。

### 2. 注册并登录

打开 <https://cyberfocus.justoky.xyz>，用邀请码注册，邮箱加密码即可，不需要第三方账号。

> 第一次登录后账本和待办都是空的，这是正常的——数据从注册那天开始积累。

### 3. 装上浏览器插件

插件负责两件事：把当前网页一键存进导航页，把浏览器新标签页换成 CyberFocus。装上之后体验差别很大，建议装。

1. 从 [Releases](https://github.com/justook/CyberFocus-online/releases/latest) 下载 `cyberfocus-ext-x.y.z.zip` 并解压
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启「开发者模式」
3. 点「加载已解压的扩展程序」，选中解压出的 `extension` 文件夹
4. 装好即可用，插件默认已连上官方实例

图解和排错见 [插件安装说明](docs/install.md)。

## 关于你的数据

- 账号下的任务、账本、专注记录、收藏和设置存在服务端，数据库是一个 SQLite 文件，由维护者运维
- 断网时数据写在本机浏览器的 IndexedDB，联网后增量同步；换设备登录同一账号即可接上
- 同一条记录在两台设备上被同时改过，会进「待确认」面板由你选，不会被悄悄覆盖
- 随时可以带走或删掉：站内「设置 → 关于」提供导出全部数据（JSON）和删除账号
- 不接第三方云同步，不接广告，不做用户画像，不把你的记录用于任何分析

关于维护者能看到什么、插件读了什么、页面向哪些地址发请求，[隐私说明](docs/privacy.md)里逐条写清了。

## 常见问题

**要自己搭服务器吗？**
不用，也暂时不能。直接用官方实例，注册即开。项目目前不提供自部署版本。

**换电脑、换浏览器，数据还在吗？**
在。登录同一个账号就行，本地只是离线缓存。

**第一次登录为什么什么都没有？**
数据在服务端，从登录那天开始记录，不会带旧版浏览器里的本地数据过来。

**能不能离线用？**
能记录，不能首次登录。已经登录过的设备断网后照常写待办、记账，联网自动补同步。

**浏览器每次启动都提示「请停用开发者模式的扩展」**
Chrome / Edge 对非商店扩展的固定提示，点「保留」即可，不影响使用。

**支持手机吗？**
网页在手机浏览器里能用，界面会收敛成单列，但没做原生 App。插件只有桌面版。

**支持 Firefox、Safari 吗？**
网页端主流现代浏览器都能用；插件目前只有 Chrome / Edge 版。

**插件会看到我浏览的所有网页吗？**
不会。只在你点图标时读当前页面的标题和地址，插件本身没有任何网络请求。

**数据能导出吗，我以后不想用了怎么办？**
能。站内「设置 → 关于」可以导出全部数据为 JSON，也可以直接删除账号，对应数据一并清除。

**发现问题、想加功能？**
到 [Issues](https://github.com/justook/CyberFocus-online/issues) 说就行。安全漏洞请别公开提，通过维护者主页的联系方式告诉我。
