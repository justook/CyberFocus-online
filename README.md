# CyberFocus

把任务、专注、记账和每天要看的信息收进一个页面。数据放在自己的服务器上，断网照常记，联网自动同步。

在线使用：<https://cyberfocus.justoky.xyz>
浏览器插件：[下载最新版](https://github.com/justook/CyberFocus-online/releases/latest)

---

## 能做什么

**安排一天**

- 待办、今日计划、本周目标三个页签，做完自动归档，想重做随时退回
- 目标可以拆成子任务，进度按子任务贡献累加，权重手动指定或自动均分
- 每天首次打开自动重置每日任务；前一天没做完的顺延到今天并带角标，不会悄悄消失
- 截止时间分紧急 / 警告 / 正常三档提醒，双击任务就能改内容和时间

**专注**

- 番茄钟带真实进度圆环，可与任务双向绑定：任务卡上开始计时就自动启动专注，反过来也行
- 专注时长与任务时长分别计账，今日 / 本月 / 今年统计一目了然

**记账攒钱**

- 一句话记账：「午饭 25 微信」自动识别金额、分类、账户和收支方向；常买的可以存成模板，下次只填金额
- 两层预算：本月总预算加分类预算，「今日建议可花」会先预留还没存完的储蓄，再按剩余天数均摊
- 攒钱计划写明目标与截止日，存钱自动推进进度，并给出每周建议存额
- 周报、月报自动汇总支出、收入、结余、分类分布与近一年趋势

**一屏看完**

- 大字号时钟，公历农历切换；旁边是「打工人时钟」——算清今天离下班还有多久，支持调休补班与奖惩记录
- 天气：当前温度、未来几天和出行建议，城市可搜索切换
- 热榜：多个来源的榜单集中在一处，显示哪些由你决定
- 多源搜索，回车即搜
- 便签：随时记一笔，页签可双击改名

**收藏**

- 分组管理常用网址，拖拽换组、排序、重命名
- 新增链接自动抓网站图标，内网地址不外发
- 配合浏览器插件一键收藏任意网页

**用着顺手**

- 背景支持动态渐变、自定义图片或每日壁纸
- 桌面三列布局，窄屏自动收敛，手机可用

## 开始使用

### 打开你的实例

访问 <https://cyberfocus.justoky.xyz>。在线服务为邀请制，向维护者索取邀请码即可开通。

> 第一次登录后账本和待办是空的，这是正常的——你的数据从注册那天开始积累。

### 装上浏览器插件

插件负责两件事：把当前网页一键存进导航页，把浏览器新标签页换成 CyberFocus。装上之后体验差别很大，建议装。

1. 从 [Releases](https://github.com/justook/CyberFocus-online/releases/latest) 下载 `cyberfocus-ext-x.y.z.zip` 并解压
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启「开发者模式」
3. 点「加载已解压的扩展程序」，选中解压出的 `extension` 文件夹
4. 装好即可用，插件默认已连上官方实例

要看图解和排错，见 [插件安装说明](docs/install.md)。

### 收藏第一个网址

在任意网页点插件图标 →「添加到导航页」，导航页会弹出填好的确认框，选好分组和图标保存就行。

## 数据放在哪

- 数据存在你（或管理员）的服务器上，数据库就是一个 SQLite 文件
- 断网也能继续记账、写待办，联网后自动增量同步；换设备登录同一个账号即可接上
- 同一条记录在两台设备上被同时改过，会进「待确认」面板由你定，不会悄悄覆盖
- 不接第三方云同步，不做行为分析

更多见 [隐私说明](docs/privacy.md)。

## 常见问题

**要自己搭服务器吗？**
不用，直接用在线服务。也可以部署自己的实例，那样数据完全在你自己机器上。

**换电脑、换浏览器，数据还在吗？**
在。登录同一个账号就行，数据跟着账号走，本地只是离线缓存。

**第一次登录为什么什么都没有？**
数据存在服务器上，从登录那天开始记录，不会带旧版浏览器的本地数据过来。

**浏览器每次启动都提示「请停用开发者模式的扩展」**
Chrome / Edge 对非商店扩展的固定提示，点「保留」即可，不影响使用。

**支持 Firefox、Safari 吗？**
网页端主流现代浏览器都能用；插件目前只有 Chrome / Edge 版。

**插件会看到我浏览的所有网页吗？**
不会。它只在你点图标时读当前页面的标题和地址，也没有任何网络请求。

**发现问题、想加功能？**
到 [Issues](https://github.com/justook/CyberFocus-online/issues) 说就行。安全漏洞请别公开提，通过维护者主页的联系方式告诉我。
