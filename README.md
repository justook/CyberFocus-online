# CyberFocus-online

CyberFocus 云端版的发布与文档仓库。**这里没有 Web 应用的源码**——应用本体是闭源的自托管项目，本仓库只提供项目介绍、浏览器插件源码与安装文档。

> 与开源版 [justook/CyberFocus](https://github.com/justook/CyberFocus)（v0.10.0 时代、单文件 + localStorage 的纯前端版）的关系：云端版从该版本分叉后完全重写为前后端分离的 Web 应用，开源版仍在独立仓库继续维护，两者互不影响。

## 这是什么

CyberFocus 是一个自托管的个人中控台：把时间管理、任务规划、专注计时、记账攒钱和信息聚合收进一个页面，数据存在你自己的服务器上，多设备离线优先同步。

### 核心模块

- **仪表盘**：大字号时钟、多源搜索、天气（Open-Meteo，无密钥）、多源热榜聚合
- **任务系统**：待办 / 今日计划 / 本周目标三页签 + 归档，父子任务与进度贡献树，跨零点自动顺延与每日任务重置
- **番茄钟**：真实进度圆环，与任务计时双向打通，今日 / 月度 / 年度专注统计
- **记账与攒钱**：一句话记账、两层预算（总预算 + 分类预算）、「今日建议可花」、攒钱计划、周报 / 月报
- **个人导航页**：分组收藏、管理面板、图标自动匹配，配合官方插件一键收藏
- **多端同步**：离线优先（IndexedDB 本地写 + 后台增量同步），冲突不静默覆盖

## 浏览器插件

`extension/` 目录是配套的 Chrome / Edge 扩展（Manifest V3）：

- **一键收藏**：在任意网页点插件图标，投递到导航页弹出预填确认框，选分组和图标后保存；投递失败自动降级为复制到剪贴板
- **新标签页直达**：浏览器新标签页直接打开你的 CyberFocus 实例

### 安装（开发者模式加载，无需商店）

1. 从 [Releases](https://github.com/justook/CyberFocus-online/releases/latest) 下载 `cyberfocus-ext-x.y.z.zip` 并解压（或直接下载本仓库 `extension/` 目录）
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择解压出的 `extension` 文件夹
4. 完成——插件默认已指向官方实例（`https://cyberfocus.justoky.xyz`），点图标即可一键收藏；自托管用户在弹窗里改成自己的实例地址即可，填一次即记住

> Chrome / Edge 对「开发者模式」加载的扩展会在每次启动时弹一次提示，属正常现象，选「保留」即可。这个插件不收集任何数据，详见 [docs/privacy.md](docs/privacy.md)。

### 权限说明

| 权限 | 用途 |
|---|---|
| `activeTab` / `tabs` | 读取当前网页的标题和地址，用于填入收藏确认框 |
| `storage` | 在本地记住你填写的导航页地址 |
| `clipboardWrite` | 投递失败时把收藏数据复制到剪贴板作为兜底 |

插件只在你点击它时工作，不监听浏览、不上传任何数据。

## FAQ

**为什么这个仓库没有源码？**
Web 应用本体闭源，本仓库只用于发布插件、项目介绍和文档。插件源码完整公开在 `extension/`，欢迎审阅。

**为什么插件不走 Chrome / Edge 应用商店？**
个人项目，商店审核与开发者账号流程较重。Edge 加载项渠道在计划中。
