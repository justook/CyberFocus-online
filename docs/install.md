# 安装浏览器插件

插件做两件事：把当前网页一键存进导航页，把浏览器新标签页换成 CyberFocus。Chrome 和 Edge 都能装，步骤一样。

插件以压缩包形式分发，需要手动加载一次，之后一直有效。

## 一、下载并解压

打开 [最新版本](https://github.com/justook/CyberFocus-online/releases/latest)，下载 `cyberfocus-ext-x.y.z.zip`，解压到以后不会被随手清掉的位置，例如 `D:\CyberFocus\`。

解压后应该是这样：

```
extension/
├── manifest.json
├── popup.html
├── popup.js
├── newtab.html
├── newtab.js
└── icons/
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

`manifest.json` 必须和其余文件在同一层。如果解压后多套了一层（变成 `extension/extension/…`），加载时会提示找不到 manifest，把里层文件夹直接拖出来即可。

## 二、加载插件

1. 在地址栏输入 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 打开页面右上角的「开发者模式」
3. 点「加载已解压的扩展程序」（Edge 叫「加载解压缩的扩展」），选中上一步的 `extension` 文件夹
4. 列表里出现「CyberFocus 导航收藏」就装好了。建议点一下「固定」，让图标常驻工具栏

## 三、第一次使用

点工具栏的插件图标，直接就能用——插件默认已连上官方实例 `https://cyberfocus.justoky.xyz`。

弹窗里的地址可以改（用于填其他实例），但当前只有官方实例可用，一般不用动。

之后在任意网页点图标 →「添加到导航页」，导航页会打开一个填好的确认框，选分组和图标、回车保存。

## 四、新标签页

装好插件后，浏览器新标签页会自动打开 CyberFocus，不再显示默认的空白页或搜索页。

想让浏览器一启动就落在 CyberFocus：

- Chrome：`设置 → 启动时` → 选「打开新标签页」
- Edge：`设置 → 开始、主页和新建标签页` → 启动时选「打开新标签页」

## 五、遇到问题

**每次启动浏览器都提示「请停用开发者模式的扩展」**
正常，手动加载的扩展没有商店签名，Chrome / Edge 每次启动都会提一句。点「保留」即可，不影响功能。

**点了「添加到导航页」没反应**
先在浏览器里直接打开实例地址，确认能登录；再看弹窗里的地址是否填对（`https://` 开头、末尾不要带路径）。

**想把新标签页还回去**
在扩展管理页把「CyberFocus 导航收藏」停用，新标签页就恢复默认；重新启用后仍用之前填的地址。

**换了新版本怎么升级**
下载新版本的 zip 覆盖原文件夹（路径保持不变），回到扩展管理页点该扩展上的「刷新」按钮。
