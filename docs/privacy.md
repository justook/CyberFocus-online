# 隐私说明

一句话：插件不联网、不收集数据；你的任务、账本和收藏只存在你自己的服务器上。

## 插件

插件没有网络请求，不上报、不埋点、不接统计服务。代码只有 `popup.js` 和 `newtab.js` 两个文件，除浏览器自带接口外不引用任何外部资源，你可以直接翻看。

它会在这些时候读数据：

| 读到什么 | 什么时候 | 用来做什么 |
|---|---|---|
| 当前网页的标题和网址 | 只有你点插件图标时 | 填进收藏确认框；你确认保存后才写入导航页 |
| 你填的实例地址 | 你保存配置时 | 存在浏览器本地，不离开你的设备 |

对应的三个权限：

- `activeTab` / `tabs`：读当前标签页的标题和地址，仅在你点击时
- `storage`：在本地记住实例地址
- `clipboardWrite`：投递失败时把收藏数据复制到剪贴板，由你自己粘贴

插件不监听你的浏览行为，不修改任何网页内容，也不注入脚本。它唯一改动的页面是浏览器新标签页——把它重定向到你配置的实例。

## 导航页里的网站图标

导航页新增链接时会去 `https://favicon.im/<域名>` 取网站图标。这个请求只带**域名**，不带路径、不带你的账号信息。

- 内网地址、IP、`localhost` 不会发往外网
- 想完全离线：编辑链接时给它选一个内置图标（不选「自动匹配」），该链接就不会再发起任何远程请求

## 你在 CyberFocus 上的数据

- 账本、任务、专注记录、收藏、设置都存在服务器的 SQLite 数据库里，也就是你（或管理员）自己的机器
- 断网时数据写在本机浏览器的 IndexedDB，联网后增量同步到服务器；两台设备各自离线改的同一笔记录，会进「待确认」面板由你选择，不会被覆盖
- 不接第三方云同步，不接广告，不做用户画像

## 第三方服务

页面本身只向以下地址发请求：

| 地址 | 用途 | 传出去的内容 |
|---|---|---|
| `api.open-meteo.com` | 天气 | 你选择的经纬度 |
| `geocoding-api.open-meteo.com` | 城市搜索 | 你输入的城市名 |
| `uapis.cn` | 热榜、每日一句、每日壁纸 | 榜单类型、日期 |
| `favicon.im` | 网站图标 | 你收藏链接的域名 |

除此之外不允许跨源请求。没有第三方统计脚本、没有社交插件、没有广告 SDK。

## 你的控制权

- 不想用插件：在扩展管理页停用，网页端功能不受影响
- 不想让图标外发：给收藏链接选内置图标
- 想带走数据：站内「设置 → 关于 → 导出我的全部数据（JSON）」
- 想彻底删除：站内「设置 → 关于 → 删除账号」，对应数据会一并清除
