# 隐私说明

> 范围：本仓库发布的浏览器插件（CyberFocus 导航收藏）。
> CyberFocus 在线站点的隐私说明见站点内「设置 → 关于 → 数据与隐私」，两处冲突时以站点内文档为准。

## 插件收集什么

**什么都不收集。** 插件没有任何网络请求，不上报、不埋点、不接入任何统计或分析服务。可以从源码验证：全部代码只有 `popup.js` / `newtab.js` 两个文件，除浏览器 API 外不引用任何外部资源。

## 插件读什么

| 数据 | 何时读 | 去哪 |
|---|---|---|
| 当前网页标题与网址 | 只在你点击插件图标时 | 用于填入收藏确认框；确认保存后才写入你的导航页 |
| 你填写的实例地址 | 保存配置时 | 存在浏览器本地（`chrome.storage.local`），不离开你的设备 |

## 权限对应关系

- `activeTab` / `tabs`：读取当前标签页的标题和地址（仅在你点击插件时）
- `storage`：在本地记住实例地址
- `clipboardWrite`：投递失败时的兜底——把收藏数据复制到剪贴板，由你自己粘贴

## 导航页的图标加载

导航页里收藏的网站图标来自 `https://favicon.im/<域名>`：打开导航页时，浏览器会向该服务发送你收藏链接的**域名**（不含路径、不含你的身份信息）。

- 内网地址、IP、`localhost` 不会发往外网
- 想完全离线：编辑链接时选择一个内置图标（非「自动匹配」），该链接即不再发起任何远程请求

## 新标签页

插件会把浏览器新标签页重定向到你填写的实例地址。除此之外它不修改任何页面内容、不注入脚本。

## 你在站点上的数据

CyberFocus 是自托管应用：账本、任务、专注记录等存在服务器（官方实例即本站服务器）的 SQLite 数据库中，不接入第三方云同步、不接入广告或行为追踪。断网时数据写在本机 IndexedDB，联网后增量同步到服务器。详见站点内隐私文档。
